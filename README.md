# The Flame Brush — theflamebrush.studio

The studio website. Hand-blown glass, photographed against black.

## How to add or change photos

Drop image files (`.jpg`, `.png`, `.webp`) into a subfolder of `images/`. Each subfolder is a **collection** — the folder name becomes the URL slug, and the prettified version becomes the default title.

```
images/
  stillwater/
    01-stillwater-no-1.jpg
    02-stillwater-no-2.jpg
    meta.json          ← optional
  coral-burst/
    01-coral-burst.jpg
    02-confetti-pair.jpg
    meta.json
```

Filenames are sorted alphabetically, so prefix with `01-`, `02-`, … to control order. The first image (alphabetically, or whichever you name in `meta.json`) becomes the **cover** for the collection card and the collection-hero banner.

### Optional `meta.json`

Drop a `meta.json` in any collection folder to override the defaults:

```json
{
  "title": "Stillwater",
  "season": "Winter 2025",
  "tagline": "Cobalt, ash, and the long blue dusk.",
  "blurb": "A study in patience. Cobalt and pearl over a clear core, frit laid down slowly...",
  "cover": "01-stillwater-no-1.jpg",
  "order": 1,
  "pieces": {
    "01-stillwater-no-1.jpg": {
      "title": "Stillwater, no. 1",
      "size": "6½″ × 4″",
      "year": "2025",
      "price": 240,
      "edition": "1/1"
    }
  }
}
```

Everything is optional. `order` controls the position of the collection on the homepage (lower = first).

## How to publish a change

1. Add or change photos in `images/`.
2. (Optional) Run `python3 build.py` locally to preview — opens nothing on its own, but updates `data/collections.json` so you can open `index.html` and check.
3. Commit and push to GitHub. The Action in `.github/workflows/deploy.yml` will regenerate `collections.json` and redeploy.

```
git add .
git commit -m "Add summer 2026 photos"
git push
```

That's it. The site rebuilds in about a minute.

## How to preview locally

```bash
python3 build.py        # build collections.json from images/
python3 -m http.server  # serve the site on http://localhost:8000
```

Then open <http://localhost:8000>.

## How to edit text / studio info

- **Studio info** (email, address, hours) is at the top of `app.js` in the `STUDIO = { … }` block.
- **About-page copy** is in the `aboutPage()` function further down in `app.js`.
- **Styling** is all in `styles.css`. The single accent color is `--ember-500` near the top of the file.
